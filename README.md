# 🌈 Landing Page - Professora Particular Lica

Este projeto é uma **Landing Page** desenvolvida como parte de uma atividade prática (PTI), com o objetivo de criar uma página web moderna, responsiva e atraente para **divulgação de serviços de aulas particulares**.

---

## 🎯 Objetivo

Apresentar os serviços da professora particular Lica de forma clara, convidativa e acessível, incentivando o visitante a **entrar em contato** e **agendar uma aula experimental**.

---

## 🧩 Estrutura da Página

A página é composta por **6 seções principais**:

1. **Cabeçalho / Apresentação**  
   Destaque do nome e slogan da professora, com imagem de perfil.

2. **Sobre Mim**  
   Pequena biografia e metodologia de ensino.

3. **Serviços**  
   Tipos de aulas oferecidas e modalidades disponíveis.

4. **Vantagens e Benefícios**  
   Motivos para escolher as aulas particulares da Lica.

5. **Depoimentos de Alunos**  
   Comentários reais de alunos satisfeitos.

6. **Contato**  
   Formulário de agendamento e links para redes sociais.

---

## 🖥️ Tecnologias Utilizadas

- **HTML5** → Estrutura da página  
- **CSS3** → Estilização e responsividade  
- **Flexbox** → Organização dos elementos e layout responsivo  
- **Font Awesome** → Ícones visuais para redes sociais e seções  
- **Google Fonts (Poppins)** → Tipografia moderna e leve

---

## 📱 Responsividade

A página foi desenvolvida com **design responsivo**, ajustando-se automaticamente a:
- Telas de computador 💻  
- Tablets 📲  
- Celulares 📱
